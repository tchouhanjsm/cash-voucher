# PR #50 — Measured contrast and dialog keyboard accessibility

**Status:** Open; exact-head CI/E2E and owner review pending.  
**Base:** `main` at `dd70819f02c564ad4df433e27342d7a53dd004b6`.  
**PR:** https://github.com/tchouhanjsm/cash-voucher/pull/50

## Outcome and acceptance criteria

- Correct the two measured source-token contrast gaps found in warning badge text and chart hover accent.
- Add a dependency-free automated contrast audit to `npm run check`.
- Ensure an idle dialog can close with Escape, restores focus to the exact opener, and retains accessible modal/title semantics.
- Do not dismiss a dialog with Escape while its primary submit button is disabled.
- No backend/API, permissions, voucher schema, accounting rules, or production behavior changes.

## Implementation

- `style.css`: warning token changes from `#9a6700` to `#895b00`; chart accent changes from `#b8862f` to `#946515`.
- `scripts/check-contrast.js`: 19 explicit foreground/background pairs, thresholds of 4.5:1 for normal text and 3:1 for graphical/focus indicators.
- `package.json`: adds `check:contrast` to the standard `npm run check` chain.
- `frontend/core/ui.js`: adds safe Escape dismissal for idle dialogs.
- `test/e2e.py`: checks modal semantics/title and Escape/focus restoration.
- `docs/ACCESSIBILITY-CONTRAST-AUDIT.md`, `docs/UI-UX-REVIEW.md`, `docs/PRODUCT-ROADMAP.md`, `docs/HANDOFF.md`, `docs/PR-HANDOFFS.md` and per-PR handoffs record the results and limitations.

## Verification evidence

- Local checks: not run in this environment.
- CI and Browser E2E: pending exact current head; authoritative links will be recorded here after workflows run.
- Contrast audit is a deterministic source-token calculation; it does not inspect every rendered state or opacity.
- Browser tests use the local mock server, not live Apps Script or Google Drive.

## Security and failure review

Only CSS tokens, shared dialog keyboard handling, tests, a Node audit script and documentation change. No new dependency or data/API contract is introduced. Escape is ignored while the primary submit action is disabled to avoid dismissing a dialog during its submit operation. Existing trusted-markup and escaped-user-value contract is unchanged.

## Release boundary

No merge, Apps Script push, deployment, live Drive operation or production-data change was performed. Owner review and merge remain required.

## Residual risks / not verified

This is not a full WCAG conformance claim. Ratios are measured for selected authored colors and do not cover every state, opacity, image, user-generated content, or computed style. Manual keyboard traversal, real screen-reader testing, zoom/reflow, reduced motion, real-device behavior and role-based usability review remain outstanding.
