## Outcome and acceptance criteria

- Selected shared text and status-color pairings meet WCAG AA normal-text contrast of at least 4.5:1.
- Selected focus indicators, control boundaries and chart accent meet 3:1 where the non-text visual is needed to identify a control or meaningful graphical object.
- Keyboard focus on dark navigation is visibly distinguishable.
- Closing the receipt dialog returns focus to the element that opened it.
- Existing responsive, financial typography, offline recovery, role and XSS regressions remain.
- No backend/API, permission, voucher schema, accounting rule or production behavior changes.

## Implementation

- `style.css`: introduce `--control-border` and `--focus-on-dark`; darken chart hover accent; use the control-border token for existing input/button/segment boundaries.
- `test/e2e.py`: compute selected contrast ratios from live CSS custom properties and assert thresholds; verify receipt-dialog focus restoration.
- `docs/UI-UX-REVIEW.md`: document measured ratios, remediations and audit limits.
- `docs/PRODUCT-ROADMAP.md`, `docs/HANDOFF.md`, `docs/PR-HANDOFFS.md`: record phase and PR state.
