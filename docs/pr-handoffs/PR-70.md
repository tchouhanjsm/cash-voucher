# PR #70 — Escape persisted voucher numbers in register and print

## Outcome

Treat voucher numbers loaded from persisted data as untrusted at HTML rendering boundaries. Escape the visible voucher number in the register and print template.

## Acceptance criteria

- Register renders `vno(voucher)` as escaped text.
- Printed voucher template renders `vno(voucher)` as escaped text.
- Browser E2E tampers with a bootstrap response to provide a hostile persisted voucher number and verifies it remains literal text in both surfaces.
- Regression asserts no injected SVG node and no payload execution.
- Rendering audit, roadmap, handoff, PR index and this dedicated handoff are updated.
- No API/schema/dependency/backend/deployment/production-data changes.
