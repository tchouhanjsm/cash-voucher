## Outcome and acceptance criteria

- The background application is inert while the shared modal is open.
- Closing the modal restores the background app's previous inert state.
- The dialog exposes modal semantics and an accessible title.
- Tab and Shift+Tab wrap focus at the dialog's first/last available controls.
- Escape does not close a dialog while its primary action is disabled.
- Escape closes an idle dialog and restores focus to the exact opener.
- No backend/API, authorization, voucher schema, accounting semantics or production behavior changes.

## Implementation

- `frontend/core/ui.js`: save and restore the app's prior `inert` state for the modal lifecycle.
- `test/e2e.py`: assert background isolation, forward/reverse focus cycling, disabled-action Escape behavior and opener focus restoration.

## Security and failure review

The change is confined to shared frontend dialog lifecycle and browser assertions. No API, permission, persistence, offline synchronization or cash-accounting behavior changes. The previous `inert` state is saved rather than blindly reset, avoiding overwriting an existing state. Nested/replaced dialogs retain the original opener and background state until the modal is closed.
