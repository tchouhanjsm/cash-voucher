# PR #71 — Full flight-test runner

## Outcome

Provide one repeatable command and one GitHub Actions workflow to execute the complete repository test suite against a single commit.

## Acceptance criteria

- `npm run test:flight` runs dependency advisory policy, `npm run check` (lint, formatting, JSON/schema checks, syntax, contrast, frontend checks and backend/unit tests), then Browser E2E.
- `.github/workflows/flight-test.yml` runs on pull requests to `main` and supports manual `workflow_dispatch`.
- Browser failure diagnostics are uploaded when available.
- Exact-head full flight workflow, normal CI and Browser E2E all pass before owner merge.
- Update handoff, roadmap, PR index, release readiness and rendering audit baseline.
- No product runtime behavior, backend/API/schema, Apps Script, deployment or production data changes.
